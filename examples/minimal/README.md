# Minimal Example

Minimal headless e-commerce backend using ESM JavaScript. Requires Node.js 26+.

Batteries included:
- Fastify
- Unchained Engine E-Commerce Framework
- Unchained Admin UI
- GraphiQL

```
npx degit unchainedshop/unchained/examples/minimal my-minimal-app
cd my-minimal-app
npm install
npm start
```
